# ChatGPT App Submission Pattern

## Core pattern

Declared behaviour must match real implementation behaviour.

## Review checks

- Tool names
- Tool descriptions
- Input schemas
- Output schemas
- Tool annotations
- Implementation side effects
- External systems touched
- Positive test cases
- Negative test cases
- Submission blockers

## Key rule

Do not infer behaviour from the tool name alone. Inspect the implementation and helper functions.

## LAB reuse

Use this pattern as the basis for app submission readiness, tool governance, and client-facing AI workflow reviews.
