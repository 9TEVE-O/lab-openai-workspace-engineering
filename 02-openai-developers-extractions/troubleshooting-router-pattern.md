# Troubleshooting Router Pattern

## Core pattern

Classify the failure before trying to fix it.

## Failure classes

- Network or sandbox issue
- Authentication or missing key
- Quota or billing exhaustion
- Rate limit
- Model, project, or organisation access
- Tool schema mismatch
- Policy or approval gate block
- Correct refusal behaviour

## LAB reuse

Use this pattern to debug Safe Intake and app workflows without treating every block as a bug.

## Review question

Was the system broken, or did a safety/control gate work correctly?
