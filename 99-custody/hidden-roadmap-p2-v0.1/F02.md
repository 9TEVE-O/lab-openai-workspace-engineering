# F02 — Opt-in plugin-provided migration sets

## Requirement

Allow installed `sqlite-utils` plugins to provide migration sets to the `migrate` command through a new plugin hook.

Add a `register_migrations()` hook to the public plugin specification. A plugin implementation of this hook may return one `Migrations` instance or an iterable of `Migrations` instances.

Plugin migration discovery is opt-in at the CLI. Add:

`sqlite-utils migrate DATABASE [PATHS...] --include-plugin-migrations`

Without that flag, migration behaviour must remain exactly as before and plugin-provided migration sets must not be considered.

With the flag:

- file/directory migration sets are discovered using the existing behaviour;
- plugin migration sets are appended after file/directory-discovered sets;
- `--list`, `--plan-json`, normal apply, `--stop-before` and `--verbose` operate over the combined set;
- each `--plan-json` entry gains a `source` field whose value is either the canonical migration file path or `plugin:<distribution-name>` where distribution metadata is available, otherwise `plugin:<module-name>`.

The same plugin must not be asked for migration sets more than once during a single `migrate` invocation.

## Acceptance

1. A test plugin can register one migration set and have it applied when `--include-plugin-migrations` is supplied.
2. The same plugin migration is absent from `--list`, `--plan-json` and apply when the flag is omitted.
3. A plugin can return multiple migration sets and their order is retained.
4. File-based sets precede plugin-provided sets.
5. `--stop-before` can target plugin-provided migrations using existing qualified and unqualified syntax.
6. `--plan-json` reports deterministic `source` values.
7. Plugin migration functions are not executed by `--list` or `--plan-json`.
8. Existing `prepare_connection` and `register_commands` plugin behaviour is unchanged.
9. Plugin loading failure produces a non-zero command result before any migration is applied.

## Boundary

Do not introduce dependencies between migration sets or concurrency/locking behaviour as part of this requirement.
