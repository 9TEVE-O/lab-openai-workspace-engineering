# Workflow Audit Proof Pack

## Plain-English summary

This proof pack shows how a workflow can be reviewed before it becomes a reusable process. The review checks the intended outcome, steps, inputs, outputs, evidence needs, review points, and next action.

The proof is that the workflow has been inspected for structure and gaps, not that the workflow is production-ready.

## Workflow map

```text
Workflow received
→ intended outcome defined
→ stages listed
→ inputs and outputs checked
→ gaps identified
→ evidence needs recorded
→ review points named
→ refinements recommended
→ readiness judgement made
```

## Evidence table

| Claim | Evidence | Status |
|---|---|---|
| The workflow has an intended outcome | Audit starts by stating the intended outcome | FACT |
| Each stage should have input, action, output, and owner | Workflow audit skill checks stage structure | FACT |
| Missing evidence should be named | Audit output includes evidence needed | FACT |
| The workflow is ready for production use | Not proven by a first audit | GAP |

## What was tested

- intended outcome clarity
- stage sequence
- input and output clarity
- owner or reviewer presence
- missing steps
- evidence needs
- review points
- readiness judgement

## What was blocked

- treating a loose idea as a finished process
- hiding missing ownership
- skipping evidence requirements
- calling a workflow ready without review points

## Human review points

- reviewer confirms the intended outcome
- reviewer checks whether gaps are acceptable
- reviewer decides whether refinements must happen before reuse
- reviewer confirms whether the next action is build, revise, test, or park

## Known limitations

- This proof pack is a documentation review pattern.
- It does not prove the workflow will perform well under real use.
- It does not replace testing with real inputs.
- It depends on the quality of the workflow description provided.

## Next decision

Convert the reviewed workflow into either a checklist, skill file, demo spec, or issue depending on what kind of reuse is needed.
