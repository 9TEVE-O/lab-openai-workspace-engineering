# Workspace Purpose

This workspace exists to stop useful AI work disappearing into random chats.

The goal is to turn repeated thinking, prompts, workflows, product decisions, research notes, and build patterns into reusable working assets.

## Transformation path

```text
Random chats
→ organised workspace
→ reusable skills
→ project folders
→ evidence trails
→ repeatable AI work
```

## What belongs here

- Reusable prompts that should become skills
- Product operating rules
- Safe Intake and ASPRON specifications
- OpenAI / Codex / MCP extraction notes
- Build checklists
- Client-facing proof packs
- Evidence trails for decisions and claims

## What does not belong here

- One-off rough chat dumps with no extracted value
- Secrets, API keys, credentials, or private client data
- Unsupported claims that look like finished documentation
- Hype documents that do not change what gets built

## Working rule

If a workflow matters, give it:

1. a place
2. a purpose
3. a repeatable process
4. a skill file
5. an evidence trail
6. a review gate
